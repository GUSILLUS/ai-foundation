# af-handoff

Передача контексту між сесіями для AI Foundation.

Handoff: збереження й відновлення стану роботи між сесіями, щоб нова сесія продовжувала з того місця, де зупинилася попередня. Дані зберігаються в ~/ai-foundation-data/, поза будь-яким git.

Плагін входить до маркетплейсу [AI Foundation](../../README.md). Встановлення:

```bash
claude plugin marketplace add GUSILLUS/ai-foundation
claude plugin install af-handoff@ai-foundation
```

## Що є (0.2.0)

**Автоматичні знімки** — з транскрипту, без моделі й без вмісту файлів:

| Подія | Що відбувається |
| --- | --- |
| `PreCompact` | знімок: останні запити, задачі, змінені й прочитані файли, записи знань, кандидати, остання відповідь (до 4 000 символів) |
| `SessionEnd` (`clear`) | те саме перед `/clear` |
| `SessionStart` (`compact`) | знімок цієї сесії повертається в контекст — доповнює підсумок стиснення |
| `SessionStart` (`clear`) | лише вказівка на свіжий (до 2 год) знімок: агент читає його, якщо ти продовжуєш ту саму роботу |
| `SessionStart` (новий старт) | вказівка на ручний handoff проєкту за останній тиждень |

Знімки лежать у `~/ai-foundation-data/projects/<клієнт>/<проєкт>/handoff/` (проєкт — за реєстром `projects.json`, як в `af-core`); незареєстровані теки — окремо, в `~/ai-foundation-data/unregistered/`. Зберігаються останні 20 автоматичних знімків; ручні не видаляються.

**Скіл `handoff`** (`/af-handoff:handoff`) — ручний handoff за шаблоном `templates/handoff.md`: стан, рішення з причинами, відкриті питання, один наступний крок, що вже вивчено, кандидати знань. Факти сесії бере скрипт `scripts/handoff.ts snapshot`. Перед записом показує наступний крок і відкриті питання й питає «Зберегти / Змінити / Не зберігати» — це рішення користувача.

Плагін ні від кого не залежить: визначення проєкту — спільна копія `lib/shared/project-registry.ts`. Кожна зміна — з тестом і записом у кореневому `CHANGELOG.md`.
