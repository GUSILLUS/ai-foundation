# af-controls

Бар’єри безпеки й бібліотека хуків для AI Foundation.

Контроль і перевірки: хуки, що захищають від небезпечних дій і читання секретів. Кожен хук безпечно деградує: якщо не може виконати перевірку, повідомляє про це й не блокує роботу. Плагін ні від кого не залежить.

Плагін входить до маркетплейсу [AI Foundation](../../README.md). Встановлення:

```bash
claude plugin marketplace add GUSILLUS/ai-foundation
claude plugin install af-controls@ai-foundation
```

## Хуки

| Хук | Подія | Що робить |
| --- | --- | --- |
| `env-guard` | `PreToolUse` (Read, Edit, Write, MultiEdit, NotebookEdit) | Блокує читання й редагування `.env`, `.env.*`, `*.env`, `.envrc`, щоб секрети не потрапляли в контекст. `.env.example`, `.sample`, `.template`, `.dist` дозволені. Команди Bash (`cat .env`) не розбирає |

Якщо хук не може виконати перевірку (зламаний вхід, внутрішня помилка), він не блокує дію, а показує попередження «перевірку пропущено».

Версія 0.1.0. Кожна зміна — з тестом і записом у кореневому `CHANGELOG.md`.
