# af-controls

Бар’єри безпеки й бібліотека хуків для AI Foundation.

Контроль і перевірки: хуки, що захищають від небезпечних дій і читання секретів. Кожен хук безпечно деградує: якщо не може виконати перевірку, повідомляє про це й не блокує роботу. Плагін ні від кого не залежить.

Плагін входить до маркетплейсу [AI Foundation](../../README.md). Встановлення:

```bash
claude plugin marketplace add GUSILLUS/ai-foundation
claude plugin install af-controls@ai-foundation
```

Статус: етап 1 — каркас. Плагін поки не містить компонентів; функціональність додаватиметься поступово, кожна зміна — з тестом і записом у кореневому `CHANGELOG.md`.
