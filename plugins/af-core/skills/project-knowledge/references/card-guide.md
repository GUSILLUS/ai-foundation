# Гайд картки проєкту

Картка — `context.md` у теці проєкту з виводу `where`; хук SessionStart підставляє її в кожну сесію, тож вона коротка: до 6 000 символів, довша обрізається по межі розділу. Шаблон — `${CLAUDE_PLUGIN_ROOT}/templates/context.md` (шлях до плагіна af-core).

## Розділи

| Розділ | Звідки факти | Порада |
| --- | --- | --- |
| Заголовок і абзац | README, `package.json` (`description`) | Що за продукт і для кого — одним абзацом |
| Стек | маніфести й lock-файли, конфіги | Мова, фреймворк, ключові бібліотеки з версіями |
| Команди | `scripts` маніфесту, Makefile, CI | Лише ті, що справді працюють; тести й лінтер обов'язково |
| Структура | верхні теки | Одна строка на теку, без переліку всього дерева |
| Конвенції | конфіги лінтера, наявний код, CONTRIBUTING | Іменування, тести, гілки й коміти |
| Джерела вимог | питай користувача | Трекер, шаблон ID, як дістати; токенів тут немає |
| Чутливі шляхи | структура, CI, міграції | Для рівня 3 рев'ю (ADR 0003) |
| Знання | генерує `index` | Між маркерами `af:knowledge` — руками не редагувати |

## Чого в картці не буває

- Секретів, значень змінних оточення, адрес внутрішніх серверів з доступами.
- Детальних флоу й крайових випадків — це записи знань.
- Тверджень без джерела.
