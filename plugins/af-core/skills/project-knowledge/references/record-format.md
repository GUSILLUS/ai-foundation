# Формат запису знань

Один запис — одна тема, до 150 рядків. Лежить у `knowledge/<гілка>/<підтема>/…/<тема>.md` проєкту або в `_shared/knowledge/…` клієнта. Службові файли починаються з `_` (`_topic.md`, `_index.md`, `_inbox/`) — їх генерує скрипт або вони не є записами.

## Frontmatter

```yaml
---
summary: Деплой у прод через GitHub Actions після апруву релізної гілки
type: process            # process | flow | feature | edge-case | decision | glossary
aliases: [деплой, викатка, release, deploy]
paths: [.github/workflows/deploy.yml, scripts/deploy/**]
sources:
  - .github/workflows/deploy.yml:12
  - зі слів користувача, 2026-11-21
verified: 2026-11-21 abc1234
---
```

- `summary` — один рядок; іде в `_topic.md`, індекс і картку.
- `aliases` — як ще називають тему; за ними хук підказує запис, коли слово з'являється в промпті.
- `paths` — маски коду, якого стосується запис; за ними `stale` бачить, що код змінився.
- `sources` — звідки кожне твердження. Без джерел запис не приймається.
- `verified` — дата й короткий коміт останньої звірки з кодом.

## Тіло

- Спершу суть у 2–3 реченнях, потім кроки чи деталі.
- Команди й шляхи — у бектиках, як у проєкті.
- Крайові випадки — окремим списком або окремим записом `edge-case`, якщо їх багато.
- Посилання на інші записи — `[[гілка/запис]]` (сумісно з Obsidian).
- Жодних секретів, значень змінних оточення й персональних даних.

## Гілки за замовчуванням

| Гілка | Що там | Де зазвичай |
| --- | --- | --- |
| `process/` | рев'ю й реліз, деплой, онбординг | спільне клієнта, якщо однаково для всіх проєктів |
| `features/<фіча>/` | `overview`, `edge-cases`, `decisions` | проєкт |
| `architecture/` | модулі, потоки даних, ключові залежності | проєкт |
| `integrations/` | зовнішні сервіси й API | проєкт або спільне |
| `glossary.md` | словник домену | спільне клієнта |

Набір — шаблон: додавай гілки, яких потребує проєкт.

## Кандидат

Файл у `knowledge/_inbox/` (чи `_shared/knowledge/_inbox/`), одна знахідка — один файл:

```yaml
---
target: process/deploy.md     # наявний чи новий запис
confidence: confirmed          # confirmed — є джерело в коді чи слова користувача; likely — висновок
sources:
  - .github/workflows/deploy.yml:12
---

Що з'ясовано й що змінити в записі.
```

## Журнал змін

`knowledge/_changes.md` — рядок на кожну правку без питання: `2026-11-23 · process/deploy.md · npm run deploy → npm run release · package.json:14`. За ним правку відкочують.
